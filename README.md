# 工业零件视觉抓取质检系统

> **在线体验（点开即用）**：https://hh200606.github.io/part-inspection/
> 上传一张工业零件图片，浏览器本地完成识别、抓取点定位与质检分级，图片不上传服务器。

一个真正面向工业零件的可视化质检工具：上传一张工业零件图片 → 模型自动识别并定位每个零件（抓取点）→ 按置信度规则判定质检等级 → 输出可导出报告。

## 核心流程（双引擎）

```
上传工业零件图片
      ↓
引擎① YOLO11n（工业零件专用模型，15 类）浏览器本地推理
      ↓ (无检出 / 检出少且低置信)
引擎② 视觉分割（背景差分 + 连通域）定位任意形状零件
      ↓
计算每个零件抓取点（中心坐标，像素 + 归一化）
      ↓
质检判定：质量分 ≥ 合格线 → 合格 / 之间 → 可疑
      ↓
可视化：抓取十字 + 分级框 + 明细表 → 导出 JSON 报告
```

### 为什么需要双引擎

YOLO11n 只对**真实拍摄**的 15 类零件（螺丝、螺母、PCB、电机等）有效。
对于 **3D 渲染图 / CAD 零件合集 / 密集小零件**（如测试图），YOLO 最高置信度往往只有 0.02，
完全检不出——这是模型训练域的限制，不是程序故障。此时视觉分割引擎（不依赖模型）
通过背景差分 + 连通域分析，能准确定位任意形状、任意类别的零件并给出抓取点。

**引擎选择**（左侧面板）：
- **自动**（默认）：YOLO 优先，无检出或结果微弱时自动切换视觉分割，取检出更多的结果
- **仅 YOLO**：识别 15 类已知零件并给出类别名
- **仅视觉分割**：定位任意零件，适合 3D 渲染 / 规则背景 / 密集合集图

## 与前项目的区别

| | 之前 | 本项目 |
|---|---|---|
| 模型 | YOLOv8n COCO 通用物体（猫、香蕉、椅子） | **YOLO11n 工业零件专用**（螺丝、螺母螺栓、PCB、电机等 15 类） |
| 入口 | 预设样图 + 工单切换 | **只上传你自己的图片** |
| 输出 | 通用目标计数 + BOM 齐套 | **抓取点坐标 + 质检等级 + 报告** |
| 基准数据 | A/B 基准对比 | 无（纯工具） |

## 使用方法

1. 打开页面（本地服务或公网链接）
2. 点击/拖拽上传工业零件图片（JPG/PNG/WEBP）
3. 调整参数：
   - **置信度阈值**：低于此值的目标不纳入统计
   - **合格判定线**：置信度 ≥ 此值判合格，之间判可疑
   - **期望零件数量**：可选，设置后数量不符直接判 NG
4. 点击「开始检测与质检」
5. 查看抓取点画面、质检结论、明细表，可导出 JSON 报告

## 可识别零件（15 类）

螺丝、螺母/螺栓、PCB 电路板、电机、电池、工具、线缆、金属型材、亚克力板、3D 打印件、塑料容器、纸箱、玻璃件、线轴、木料

> 这是创客/工业场景的零件检测模型，对螺丝和 PCB 精度较高。若你的零件不在上述类别中，模型不会识别——这是模型能力边界，不是 bug。

## 质检规则说明

本系统的"质检"是**基于检测置信度的分级判定**，不是专业的缺陷分割检测：
- 置信度 ≥ 合格线 → 合格（绿色，可抓取）
- 阈值 ≤ 置信度 < 合格线 → 可疑（黄色，建议人工复检）
- 置信度 < 阈值 → 忽略

这是快速分选场景的实用做法。若需要毫米级缺陷检测（划痕、裂纹），需要专门的缺陷检测模型。

## 技术说明

- 纯前端：ONNX Runtime Web（WASM）在浏览器本地推理，图片不上传服务器
- 模型：`models/yolo11n_makerspace.onnx`（10 MB，opset17，输入 640×640，输出 `[1,19,8400]`）
- 预处理：letterbox + RGB→CHW（正确处理 RGBA 四通道）
- 后处理：逐类 NMS，坐标还原到原图
- 模型来源：huggingface.co/pavanyadava07/makerspace-yolo11n（CC BY-NC-SA 4.0，非商用）

## 什么样的图片能检出（重要）

两套引擎各有前提条件，选错模式就会「检不出」：

| 模式 | 适用图片 | 不适用 |
|---|---|---|
| 仅 YOLO 模型识别 | **真实拍摄**的螺丝、螺母/螺栓、PCB、电机、电池、工具、线缆等 15 类零件；背景干净、光照正常、零件不过小 | 3D 渲染 / CAD 截图 / 零件合集 / 不在 15 类内的物体 |
| 仅视觉分割定位 | **背景与零件明暗差异明显**的图片：纯色/渐变背景、规则排布、3D 渲染、密集小零件 | 背景杂乱、零件与背景同色、零件互相粘连成一片 |
| 自动（默认） | 先跑 YOLO，结果弱时自动切视觉分割；覆盖以上两类 | 同上两者的共同限制 |

要点：零件与背景要有明暗/颜色反差；零件彼此不要粘连；单个零件别太小（建议 ≥ 40×40 像素）。若视觉分割漏检，调低「分割灵敏度」（更敏感）；若噪声多，调高灵敏度并增大「最小面积」。

## 本地运行

```bash
cd part-inspection
python -m http.server 8002
# 浏览器打开 http://localhost:8002
```

> 必须通过 HTTP 服务访问，不能用 `file://` 直接打开（浏览器安全策略禁止读取本地 ONNX 模型）。首次加载需联网从 CDN 获取 ONNX Runtime Web 脚本。在线版已部署在 GitHub Pages，无需本地服务。
